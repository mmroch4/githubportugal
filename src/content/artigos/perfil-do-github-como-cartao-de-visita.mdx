Quando alguém quer saber o que fazes como programador, seja um recrutador, um mantenedor que está a rever o teu pull request ou alguém que encontrou o teu projeto, muitas vezes a primeira paragem é o teu perfil do GitHub. Em poucos segundos, essa pessoa tenta perceber quem és e no que trabalhas.

A boa notícia é que bastam umas horas para o perfil passar de uma lista de repositórios a um bom cartão de visita.

## Começa pelo básico

- **Foto e nome:** uma foto em que se vê a tua cara (ou um avatar que uses em todo o lado) e o teu nome verdadeiro, se te sentires confortável. Ajuda as pessoas a reconhecer-te noutros sítios.
- **Bio:** uma frase sobre o que fazes e o que te interessa. "Programador backend no Porto, interessado em bases de dados e Rust" diz muito mais do que "Developer".
- **Localização:** escrever "Portugal" ou a tua cidade ajuda a comunidade a encontrar-te. É, por exemplo, uma das formas de entrares no [ranking](/ranking) do GitHub Portugal.
- **Links:** o teu site, blogue ou LinkedIn. Se tiveres um endereço de email público para contactos, este é o sítio.

## Escreve um README de perfil

Se criares um repositório público com o mesmo nome que o teu login (por exemplo, `mmroch4/mmroch4`) e lhe puseres um ficheiro `README.md`, o GitHub mostra esse ficheiro no topo do teu perfil.

É o sítio ideal para te apresentares em mais do que uma frase. Algumas ideias:

- Em que estás a trabalhar agora e o que estás a aprender.
- Dois ou três projetos de que te orgulhas, com uma linha a explicar cada um.
- Como é que as pessoas te podem contactar.

Mantém-no curto. Um README de perfil cheio de emblemas, gráficos e estatísticas parece impressionante, mas quem o visita quer sobretudo perceber rapidamente quem és. Se usares imagens, acrescenta sempre um texto alternativo, para quem usa leitores de ecrã.

## Fixa os repositórios certos

Por defeito, o GitHub mostra os repositórios mais populares. Em vez disso, podes escolher até seis repositórios para fixar no perfil, incluindo projetos de organizações para os quais contribuíste.

Escolhe os que melhor mostram aquilo que queres fazer a seguir, não necessariamente os que têm mais estrelas. E garante que cada um tem:

- Uma **descrição** de uma linha (aparece no cartão do repositório).
- Um **README** que explica o que o projeto faz, como se instala e como se usa.
- **Tópicos** (as etiquetas do repositório), que ajudam as pessoas a encontrá-lo.
- Uma **licença**, para o código ser de facto aberto. O capítulo sobre [licenças](/guia/licencas) do nosso guia ajuda-te a escolher.

## Mostra as tuas contribuições

O gráfico de contribuições mostra a tua atividade ao longo do ano. Duas definições fazem diferença:

- **Contribuições privadas:** se trabalhas sobretudo em repositórios privados, podes ativar nas definições do perfil a opção de mostrar contribuições privadas. Aparecem só como quadrados no gráfico, sem revelar nada sobre os repositórios.
- **Email dos commits:** os commits só contam para o teu perfil se forem feitos com um email associado à tua conta. Se o gráfico parece vazio apesar de trabalhares todos os dias, confirma o email configurado no Git com `git config user.email`.

Não te preocupes com manter o gráfico sempre verde. Ninguém sério avalia um programador pela quantidade de quadrados, e descansar também faz parte.

## Contribui para outros projetos

Nada mostra melhor como trabalhas do que contribuições para projetos de outras pessoas: o código, a forma como descreves o problema numa issue e como respondes à revisão de um pull request.

Se não sabes por onde começar, a página de [primeiras contribuições](/primeiras-contribuicoes) junta issues marcadas como boas para quem está a começar, em projetos open source portugueses.

## Uma lista para rever o teu perfil

1. A foto, o nome e a bio dizem quem és e o que fazes?
2. Tens um README de perfil curto e atualizado?
3. Os repositórios fixados são os que queres mostrar, e todos têm descrição, README e licença?
4. Os teus commits estão associados à tua conta?
5. Há pelo menos uma contribuição para um projeto que não é teu?

Se respondeste "sim" a tudo, o teu perfil já conta uma boa história. Se ainda não, escolhe um ponto e trata dele esta semana.
